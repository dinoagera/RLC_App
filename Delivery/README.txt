RLC / LAB — исходный проект по ТЗ №32

RLC_Lab_Source.zip — исходники Unity 6/C#, самостоятельная браузерная версия,
тесты, ресурсы и русская документация. Распакуйте архив, откройте README.md.

RLC_Lab_Windows_x64.zip — готовая Windows x64-сборка. Распакуйте её целиком
и запустите RLC Lab.exe. Unity, Python и .NET для запуска не нужны.

Для браузерной версии: Python 3 → Start-Lab.sh / Start-Lab.bat.
Для Unity: добавить распакованную папку RLC_Lab в Unity Hub и открыть Laboratory.unity.

Unity 6000.0.62f1: 15 EditMode- и 2 PlayMode-теста пройдены.
Windows x64-сборка успешно запущена под Wine.
Отдельная проверка на Windows-ПК и профилирование ещё не выполнены.
Инструкции и список приёмочных проверок: README.md и Docs/ACCEPTANCE.md.
