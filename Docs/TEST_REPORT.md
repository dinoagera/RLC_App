### C# — исходный расчётный модуль

Команда:

```bash
dotnet run --project tools/MathTests/MathTests.csproj -c Release
```

Результат: **PASS, 19 952 проверки**, .NET SDK 9.0.318.

- Численные значения контрольного примера ТЗ.

- Знаки φ ниже и выше резонанса.
- Обе включённые границы ±2% и ближайшие внешние значения.
- Все **32** сочетания минимумов/максимумов пяти параметров.

- Конечность результатов, Z≥R, Iₘ≤Uₘ/R, векторное сложение напряжений.

- Разбор точки/запятой, отклонение NaN/Infinity/переполнения/текста.
