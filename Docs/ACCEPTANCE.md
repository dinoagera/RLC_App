## Завершение приёмки в Unity

1. Установить указанную Unity 6 LTS и Windows Build Support (Mono), активировать лицензию.
2. Открыть проект, дождаться импорта и убедиться, что Console не содержит ошибок.
3. Выполнить EditMode и PlayMode тесты. Оба запуска должны завершиться успешно.
4. Открыть `Laboratory.unity` и проверить, что все кириллические символы, индексы, поля и кнопки видимы.
5. Проверить исходные значения: Z≈100,00 Ом, φ≈−0,24°, f₀≈50,329 Гц.
6. На паузе изменить каждый из пяти параметров: результаты и текущий график должны обновиться.
7. Проверить `NaN`, пустое поле, текст, 0, −1, превышение верхнего диапазона; действующий параметр не меняется.
8. Переключить три режима, нормализацию; проверить цвета и подписи осей.
9. Настроить резонанс. Z=R, Iₘ=Uₘ/R, φ≈0; индикатор включён.
10. Для R=1 Ом, L=500 мГн, C=1 мкФ проверить узкий пик. Для L=C=1 проверить сообщение о f₀ вне диапазона.
11. Изменить скорость: f и рассчитанные значения не меняются. Проверить паузу, старт и сброс.
12. Открыть справку, прокрутить до конца, закрыть Esc. Ввод в поля не должен запускать горячие клавиши.
13. Перезапустить приложение и проверить восстановление параметров, скорости и режима.
14. В Game View / Windows проверить 1920×1080, 1366×768, 1280×720, 1024×768; элементы не должны выходить за окно.
15. С помощью Profiler в Development Build проверить 60 FPS на целевом ПК и задержку от изменения параметра до обновлённого кадра ≤100 мс.
16. Выполнить **RLC Lab → Собрать Windows x64**. Проверить всю папку на Windows 10/11 x64 без установленного Unity.
17. Передать папку сборки целиком и сохранить лог успешной сборки. Только после этого отмечать пункт Windows-сборки выполненным.
