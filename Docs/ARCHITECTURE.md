# Архитектура

## Unity

Расчётный код в `Assets/RLCLab/Core` — отдельная сборка с `noEngineReferences: true`. Он не обращается к сцене, `MonoBehaviour`, `Mathf` или PlayerPrefs. Те же исходники подключаются в консольные .NET-тесты без копирования.

| Файл | Ответственность |
|---|---|
| `CircuitParameters.cs` | Пять параметров в пользовательских единицах, диапазоны, конечность и разбор чисел |
| `CircuitCalculator.cs` | Чистый расчёт установившегося режима; функции сигналов и Z(f) |
| `ResonanceDetector.cs` | Проверка относительного расстояния до f₀ |
| `FrequencySampler.cs` | Логарифмическая сетка с точным резонансом и локальным уточнением |
| `CircuitController.cs` | Изменение и валидация параметров, перерасчёт, события, PlayerPrefs |
| `SimulationManager.cs` | Время развёртки, скорость, старт/пауза/сброс |
| `UIController.cs` | Создание uGUI/TMP, обработка ввода, результаты, режимы, справка |
| `LabTheme.cs` | Цвета, элементы управления, размещение и типографика |
| `LineGraphic.cs` | Пакетирование отрезков в UI-сетку через `VertexHelper` |
| `CircuitSchematic.cs` | Схема, подписи, визуальное направление тока |
| `GraphRenderer.cs` | Временные графики и частотные характеристики |
| `PhasorDiagram.cs` | Векторы, масштаб напряжений и фазовый угол |
| `ProjectSetup.cs` | Параметры проекта, стартовая сцена, сборка Windows x64 |

Поток:

```text
uGUI / TMP
    ↓
UIController → CircuitController → CircuitCalculator
                       ↓ Changed
            результаты / схема / GraphRenderer / PhasorDiagram

SimulationManager → только фаза развёртки и визуальная анимация
```

`Parameters` возвращает копию: внешнее изменение объекта не может незаметно обойти контроллер. `CircuitResult` — неизменяемая структура. Ввод за пределами диапазонов отклоняется, не обрезается молча. Восстановление из PlayerPrefs проверяет каждую величину; повреждённые значения заменяются исходными.

### Сцена и ресурсы

`Assets/Scenes/Laboratory.unity` содержит `UIController`. Его `Awake` создаёт Canvas, EventSystem, контроллеры и элементы интерфейса. Не требуется ручных ссылок в инспекторе.

CanvasScaler: 1920×1080, режим Expand. При уменьшении разрешения сохраняется компоновка, для другого соотношения сторон увеличивается доступная виртуальная область. Полноэкранное окно можно переключить стандартным Unity-сочетанием Alt+Enter.

Шрифт DejaVu Sans с кириллицей включён в `Resources/Fonts`; TMP-атлас создаётся динамически с поддержкой нескольких текстур. TMP Essential Resources включены заранее. Неиспользуемые URP/HDRP Shader Graph-ресурсы исключены: проект использует Built-in Pipeline и UI Mesh API.

### Перерисовка

Сетки строятся одной Graphic на график, не отдельным объектом на точку. При паузе временной график обновляется только при изменении параметров/режима/размера. Частотная характеристика и векторная диаграмма не пересоздаются каждый кадр. Сетка частот кэшируется до изменения цепи.

PlayerPrefs сохраняются не на каждом событии ползунка: запись отложена и дополнительно выполняется при уходе/выходе из приложения.

## Физическая модель

Пользовательские единицы:

```text
R: Ом      L: мГн → L·10⁻³ Гн      C: мкФ → C·10⁻⁶ Ф
f: Гц      Uₘ: В
```

Внутренние величины — `double`, тригонометрические углы — радианы.

```text
ω = 2πf
Xₗ = ωL
X꜀ = 1/(ωC)
Z = √(R² + (Xₗ − X꜀)²)
Iₘ = Uₘ/Z
φ = atan2(Xₗ − X꜀, R)
f₀ = 1/(2π√LC)

u(t) = Uₘ sin(ωt)
i(t) = Iₘ sin(ωt − φ)
```

Положительный φ означает отставание тока. На фазовой диаграмме фаза тока принята за ноль: комплексное U = IₘR + jIₘ(Xₗ − X꜀). Поэтому `atan2(U.Im, U.Re) = φ`.

Ток и напряжение имеют разные размерности. На временном графике без нормализации используется общая числовая шкала с явными единицами В / А; нормализованный режим делит каждый сигнал на собственную амплитуду. На векторной диаграмме ток вынесен на самостоятельную опорную ось.

### Резонанс

Индикатор: `abs(f−f₀)/f₀ ≤ 0.02`; небольшой допуск `1e-14` компенсирует машинную погрешность на точной границе 2%. При настройке на резонанс передаётся полное `double` f₀; форматирование текста не участвует в расчётах.

Частотная сетка: 560 логарифмических точек между 1 и 1000 Гц + текущая f + до 97 локальных точек с шагом полосы `Δf/16`, где `Δf = R/(2πL)`. Точное f₀ включается при попадании в диапазон. Это предотвращает занижение максимума в высокодобротной цепи.

Для всех допустимых значений R≥1 и f,L,C>0. Делители ненулевые. Дополнительно публичные функции проверяют корректность параметров до вычислений.

### Анимация

Переменная `PhaseCycles` задаёт начальную фазу временного окна в циклах. Видимое время:

```text
t = (PhaseCycles + 3·x) / f,     x ∈ [0,1]
d PhaseCycles / d wallTime = 0.35 · Speed
```

Поэтому отображаются именно физические сигналы на оси t, но движение окна намеренно замедлено. Изменение `Speed` не меняет f, ω, Z или φ. Положение окна периодически сворачивается на целое число периодов для ограничения численного диапазона.

## Браузерная версия

`math.mjs` — независимая реализация тех же формул. `plots.mjs` — HiDPI Canvas 2D, `app.mjs` — DOM, события, сохранение, режимы и развёртка. Схема — SVG. Сервер `tools/serve.py` только раздаёт локальные статические файлы, слушает 127.0.0.1 и ничего не вычисляет.

`Web/tests/csharp-fixtures.json` содержит 96 наборов результатов, полученных запуском C#-модуля: 32 крайних сочетания и 64 случайных. JS-тест сравнивает их с относительным допуском 10⁻¹².

Браузерные функции под курсором, частотный выбор и CSV — дополнительные удобства; они не заменяют требуемые Unity-компоненты.
